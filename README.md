Instagram User Analytics Using Machine Learning

Overview

Instagram User Analytics is a Machine Learning project designed to analyze Instagram user engagement and predict post performance based on account metrics and posting behavior. The system performs data preprocessing, exploratory data analysis, engagement visualization, word cloud generation, and machine learning-based prediction of likes using Instagram activity data.

Project Objectives

• Analyze Instagram user engagement patterns.

• Visualize caption and hashtag trends.

• Study the relationship between followers and likes.

• Predict expected likes on posts using Machine Learning.

• Provide data-driven insights for content optimization.

Features

✓ Instagram dataset analysis

✓ Caption word cloud generation

✓ Hashtag word cloud generation

✓ Engagement visualization

✓ Follower vs Likes regression analysis

✓ Likes prediction using Gradient Boosting Regressor

✓ Performance evaluation and visualization

Dataset Information

Source: Kaggle

The dataset contains Instagram post statistics such as Followers, Likes, Caption, Hashtags, and Time Since Posted. The dataset consists of more than 100 records and is used for engagement analysis and predictive modeling.

Technology Stack

Programming Language: Python

Libraries: Pandas NumPy Matplotlib Seaborn WordCloud Scikit-learn

Machine Learning Algorithm: Gradient Boosting Regressor

Model Information

Input Features: • Followers • Time Since Posted

Target Variable: • Likes

Algorithm: Gradient Boosting Regressor

The model learns engagement patterns from existing Instagram data and predicts the expected number of likes based on posting time and follower count.
