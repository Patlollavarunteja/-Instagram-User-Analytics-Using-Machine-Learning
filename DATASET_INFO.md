Dataset Information

Dataset Name: Instagram_dataset.csv

Source: Kaggle

Domain: Social Media Analytics

Project: Instagram User Analytics Using Machine Learning

Description

The dataset contains Instagram user engagement information and post statistics used for exploratory data analysis, visualization, and machine learning prediction.

The dataset is designed to analyze how different factors influence engagement levels on Instagram posts.

Dataset Features

• Followers

• Likes

• Caption

• Hashtags

• Time Since Posted

• User Engagement Metrics

Dataset Size

Total Records: 104+

Data Format: CSV

Purpose of Dataset

The dataset is used to:

• Study Instagram user behavior

• Analyze engagement patterns

• Create visual analytics

• Generate caption and hashtag word clouds

• Predict post likes using machine learning

Machine Learning Target

Target Variable: Likes

Input Features: Followers Time Since Posted

Preprocessing Performed

• Missing Value Handling

• Feature Scaling

• Time Conversion to Numerical Format

• Data Cleaning

Applications

• Influencer Analytics

• Social Media Marketing

• Content Optimization

• Audience Analysis

• Engagement Prediction

Limitations

• Small dataset size

• Limited number of engagement features

• Not suitable for real-time analytics without additional data sources

Future Improvements
